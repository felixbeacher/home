# Felix Beacher — A world of curiosity

A personal homepage linking seven published projects across Science, Mathematics, Games and Dashboards.

Live homepage: https://felixbeacher.github.io/home/

## Editing

All page content, artwork, styles and category filtering are in `index.html`. Edit a project card to update its title, description or link. New cards can be added to the relevant category section. Update the total project count if you add or remove projects.

The page uses no external fonts, libraries, image services or build tools. Open `index.html` directly to preview it.

## Hosting

GitHub Pages is configured to publish from the `main` branch and `/ (root)` folder. Changes committed to `index.html` publish automatically after GitHub finishes deployment.
