# Felix Beacher — The Curiosity Cabinet

A personal homepage with a description-only Home view and five categories: Science, Maths, Games, Medical AI and Spiritual. Includes seven published projects, The Medical AI Podcast and five spiritual videos.

Live homepage: https://felixbeacher.github.io/home/

## Editing

All page content, artwork, styles and category filtering are in `index.html`. Edit a project card to update its title, description or link. New cards can be added to the relevant category section. Category link counts are calculated automatically. Update the category total if you add or remove categories.

The page uses no external fonts, libraries, image services or build tools. Open `index.html` directly to preview it.

## Hosting

GitHub Pages is configured to publish from the `main` branch and `/ (root)` folder. Changes committed to `index.html` publish automatically after GitHub finishes deployment.

## Animation

The orbital artwork rotates with a play/pause control. It starts paused for visitors whose system requests reduced motion; they can explicitly choose Play animation.
